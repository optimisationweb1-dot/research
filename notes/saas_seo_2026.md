## TL;DR

1. **Рельс для SaaS с криптовыплатой есть и проверен на странице провайдера:** Creem принимает продавцов из Молдовы («Moldova ✓») и платит **USDC в сети Polygon за 2% от суммы выплаты**, минимум $50/€50, выплаты 1-го и 15-го, холд 7–12 дней [provider docs, 26.09.2026]. Банковская выплата — 7 USD/EUR или 1% (что больше). Комиссия за продажу — 3.9% + $0.40 (база). Итого на цикл «продажа → USDC» ≈ 5.9% + $0.40 [оценка: 3.9% + $0.40 за продажу + 2% за USDC-выплату; потери на конвертации валют — нет данных]. Dodo и Freemius в крипту не платят (Dodo — только фиат на банк; Freemius — PayPal/Payoneer/wire/Wise).
2. **Покупатели из РФ и Беларуси через MoR недоступны:** Creem прямо перечисляет Russia и Belarus в неподдерживаемых странах [provider docs]. Значит, Яндекс-инструменты (Яндекс — 70.35% поиска в РФ, Statcounter 08.2026) и WB/Ozon-инструменты для российских селлеров — **тупик по выплатам** без обхода блокировок (исключено правилами проекта).
3. **Рынок AI-visibility / GEO огромный наверху и пустой внизу.** Наверху: Profound — $180 млн при оценке $1.8 млрд (15.09.2026) [press], Peec AI — $10 млн ARR (23.05.2026) [press], Otterly — от $29/мес, «40 000+ пользователей» [vendor]. Внизу (TrustMRR, выручка по Stripe, 26.09.2026): из 21 инди-GEO-трекера **медиана MRR ≈ $50**, ≥$1k MRR — 5 (Rank Prompt $37 867, Mentionable $3 750, Promptmonitor $2 473, AEO Checker $1 139, GetMentioned $1 096), 7 — $0 [provider data]. Входить можно только с отличием (языки CEE, white-label + внедрение исправлений), а не «ещё один дашборд».
4. **Самый недооценённый формат — платный hosted MCP-сервер для SEO-данных** (GSC + GA4 + CrUX + краулинг + валидация schema) для пользователей Claude/ChatGPT/Cursor. Advanced GSC MCP основан в 2026 г., DR 4, и уже имеет **$4 266 MRR** (TrustMRR, 26.09.2026) [provider data] при ценах $15/$40/$105 [provider docs]. Флот владельца — на Claude, это его «родная» технология. Бесплатный конкурент — open-source mcp-gsc (1.7k звёзд на GitHub, v0.4.1 09.2026) [provider data]; поэтому ценность — в хостинге, OAuth, CrUX/краулинге и сводных отчётах, а не в голом доступе к GSC.
5. **Что продаётся у инди лучше всего — «сделано за вас», а не трекеры.** Самые большие SEO-строки TrustMRR: AEO Engine $129 571 MRR (AI SEO-агентство), RankAI $56 533, SEOBOT $39 538, ChatSEO $29 084 (контент-автопилоты) [provider data]. Для владельца это аргумент за гибрид: SaaS-модуль как вход + внедрение исправлений как услуга (Upwork, N7/N9/N18 из `niches_b2b_services.md`).
6. **Тупики с доказательствами:** генераторы llms.txt (526 плагинов в WordPress.org, бесплатный лидер — 40 000 установок; Google не использует llms.txt; инди-сервисы — $41–47 MRR); «индексаторы» ссылок через Indexing API (API только для JobPosting/BroadcastEvent) [official]; конструкторы programmatic SEO без уникальных данных (спам-апдейт 18–21.08.2026); Amazon (SP-API: в 11.2025 объявили $1 400/год, 12.05.2026 отменили — платформенный риск) [vendor/press].
7. **Рекомендация (топ-3, одно ядро кода):** SS-01 hosted SEO MCP → SS-02 GEO-трекер с white-label и языками RO/RU/UA/PL + «fix»-услугой → SS-03 CWV-монитор на CrUX API как модуль того же ядра. Реалистичный суммарный MRR через 6 месяцев — **$1 500–2 500** [оценка: сумма потолков SS-01…SS-03 × 0.8 на пересечение аудиторий], вероятность первой оплаты за 30 дней по портфелю ≈ 0.4 [оценка: при независимости 1 − 0.75 × 0.8 × 0.88 ≈ 0.47; продукты делят аудиторию и ядро, события коррелированы, поэтому берём ~0.4].

## 4. Топ-5 и как их собрать в одну систему

1. **SS-01 Hosted SEO MCP** (балл 100) — ядро. Весь SEO-«движок» (GSC, CrUX, краулер, schema, логи) пишется один раз, MCP — интерфейс для ИИ-агентов, веб-кабинет — для людей.
2. **SS-02 GEO-трекер CEE + fix** (50) — второй продукт на том же ядре + мост к услугам Upwork (N9 «GEO-аудит с внедрением», N18 «structured data»).
3. **SS-03 CWV-монитор** (27) — модуль ядра, дешёвый (CrUX бесплатен).
4. **SS-05 EAA/WCAG-монитор** (15) — модуль ядра + воронка в аудиты (N1/N2), единственный кандидат с доказанной большой публичной выручкой в нише (AudioEye).
5. **SS-04 / SS-07 / SS-06** (12–14) — модули, включаются по спросу.

## 5. Ловушки и тупики (с доказательствами)

1. **llms.txt как продукт.** Google не использует llms.txt [press: SE Roundtable/SEJ, 2025]; 526 плагинов, бесплатный лидер — 40 000 установок, встроено в Yoast/AIOSEO [provider data]; инди-сервисы — $41–47 MRR [provider data]. Только как бесплатная функция.
2. **«Индексаторы» через Google Indexing API.** API разрешён только для страниц с JobPosting или BroadcastEvent в VideoObject; попытки обхода квот — отзыв доступа [official: developers.google.com/search/apis/indexing-api]. С 10.2025 одобрение повышения квот остановлено [vendor-блог, проверить]. IndexBolt при этом зарабатывает ~$3 943/мес [provider data] — это не доказательство легальности. Исключено (нарушение правил платформы).
3. **Конструктор programmatic SEO «под ключ».** Scaled content abuse «no matter how it's created» [official]; спам-апдейт 18–21.08.2026 ударил по scaled/AI/programmatic-сайтам [press/vendor]. Риск отзывов и возвратов. Делать только аудитор риска (SS-06) или pSEO на уникальных данных клиента (услуга N10).
4. **Скрейпинг UI ChatGPT, Google SERP / AI Overviews, Google Maps (локальные grid-трекеры).** Против ToS платформ → в проекте исключено. Покупка тех же данных у SERP-API-вендоров (DataForSEO и т. п.) переносит ToS-риск на вендора, но не снимает его — решение владельца, помечено «серое». Локальные трекеры (LocalRank.so $25 954 MRR, Local SEO Bot $12 081 [provider data]) показывают спрос, но строятся на данных Google Maps.
5. **Яндекс- и WB/Ozon-инструменты для российских клиентов.** Creem прямо не принимает покупателей из России и Беларуси [provider docs]; обход через P2P, платёжных агентов, чужие карты — ловушка (база `STATUS.md` 2.8).
6. **Amazon SP-API.** Объявленные в 11.2025 сборы ($1 400/год + $0.40 за 1 000 GET) отменены 12.05.2026 [vendor/press] — но сама сага показывает: платформа может в одностороннем порядке ввести плату; рынок занят.
7. **Etsy Commercial Access.** Мультиселлерный доступ — только после ручного ревью, запрет скрейпинга и требования к бренду [vendor + developers.etsy.com]. Продавать до одобрения нельзя (правило честных тестов).
8. **Оверлеи доступности / обещание «compliance».** FTC: accessiBe $1 млн (база). Только «аудит/мониторинг с перечнем найденного».
9. **ExtensionPay / Stripe для расширений.** Только Stripe, Молдова не поддерживается (база). Использовать Creem.
10. **Otterly-подобный дашборд без отличия.** Медиана инди-GEO-трекера на TrustMRR ≈ $50 MRR, 7 из 21 — $0 [provider data]. Дашборд без языков/внедрения — в хвост распределения.
11. **Google OAuth без верификации.** Лимит 100 новых пользователей и экран «unverified app» [provider docs] → подать на верификацию в первую неделю.
12. **Выплата USDC на SRL.** Юрлицо, получающее крипту, — вопрос для бухгалтера (закон 308/2017, лимит 50 000 лей/мес на операции с зарубежными провайдерами — база). Смешивать «продавец SRL» и «выплата на личный кошелёк» нельзя — это искажение получателя.
