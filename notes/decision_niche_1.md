# Решение: ниша №1 и план на 14 дней

Дата: 26.09.2026. Основа: `notes/niches_software.md`, `notes/niches_b2b_services.md` (+ `.csv`). Все вероятности и потолки — [оценка] исследователей, формулы в заметках.

## Допущения по умолчанию
- Деньги — на Global Web SRL (IT Park) или на физлицо через Upwork → OTP. Налоговую оптимизацию решаем после первого дохода (решение пользователя 26.09).
- Английский — только письменно; холодных рассылок нет; бюджет теста ≤ $150.

## Выбор
**Ниша №1 — «технический SEO, который мы сами внедряем» на Upwork** для агентств и магазинов US/UK/EU:
- внедрение structured data (Product, Merchant listings) с валидацией (N18);
- Core Web Vitals для WordPress/Shopify (N17);
- white-label технический аудит с планом исправлений (N7) — как вход к внедрению.

Почему:
- сильнейший навык владельца (15+ лет SEO), флот делает 80% работы (краулинг, Lighthouse/CrUX, код), владелец проверяет;
- выплата Upwork → банк Молдовы подтверждена (Direct to Local Bank, $0.99, мин. $5);
- асинхронно, письменно; спрос есть (1 661 открытая вакансия Technical SEO — поисковая выдача, дата неизвестна, проверить);
- внедрение (код) — вероятно CAEM 62.01, т. е. IT-доход (подтвердить у MITP); «чистый» SEO-аудит — не IT;
- первый доход: 1–3 недели [оценка].

**Параллельно, пассивно — Apify Store, портфель SEO-actors** на официальных API (CrUX Core Web Vitals, аудит готовности к ИИ-краулерам). Те же знания, та же разработка. Выплата SWIFT юрлицу от $100 [provider docs]; деньги реально на 50–60-й день. С 01.10.2026 только pay-per-event.

**Не сейчас:** лидген по pickaroofer (выплаты из США без Stripe/Payoneer сложны, не IT, 30 дней не хватит); EAA-аудиты как основной продукт (штрафов нет, спрос в Apify почти нулевой) — оставить как допуслугу; Telegram Stars (крипта → банк ограничена).

## План на 14 дней
| День | Что | Кто |
|---|---|---|
| 1 | Создать аккаунт Upwork (физлицо или Agency на SRL — решить), пройти верификацию, привязать OTP | владелец |
| 1–2 | Профиль EN: фокус «Technical SEO implementation: schema, Core Web Vitals, indexing», 3 кейса (свои сайты, pickaroofer.com) | флот пишет, владелец правит |
| 2–3 | 3 позиции в Project Catalog: «Product schema + Merchant listings fix — $150», «CWV fix for WordPress — $250», «Technical SEO audit + fix plan — $200» | флот |
| 2–4 | Пайплайн: краулер + Lighthouse/CrUX + валидатор schema → отчёт-шаблон | флот |
| 3–14 | 2–3 отклика в день только на подходящие вакансии, первые проекты по сниженной цене ради отзывов (~30 откликов ≈ $72 в Connects) | флот готовит, владелец отправляет |
| 5–10 | Apify: аккаунт, 2 actors (CrUX CWV, AI-crawler readiness), pay-per-event | владелец (аккаунт), флот (код) |
| 14 | Итог: отклики → ответы → заказы; решение масштабировать или менять нишу | вместе |

Критерий успеха через 14 дней: ≥1 оплаченный заказ или ≥3 диалога с клиентами. Иначе — переход на N11 (локализация EN→RO) или N2.

## Проверить
- Upwork: вывод на счёт SRL (Agency) или только физлицо.
- Классификация доходов (внедрение vs аудит) по CAEM в MITP.
- Актуальное число вакансий Upwork (страницы за Cloudflare).
