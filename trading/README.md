# trading/ — прототипы (27.09.2026)

Личный трейдинг, не бизнес-направление проекта. ТЗ — `../notes/trading-bot/spec.md`. Python 3.10+, без зависимостей.

| Файл | Что делает | Данные |
|---|---|---|
| `gex_levels.py` | Call Wall, Zero Gamma, Put Wall для BTC/ETH: все экспирации, 0DTE, 1DTE | Deribit public API, без ключей |
| `volume_anomaly.py` | Аномальные объёмы 5m/15m: RVOL, дельта, поглощение, климакс, дивергенция, снятие ликвидности + проверка на истории | Binance USD-M klines (`data.binance.vision` или live `fapi`) |
| `smc_backtest.py` | Бэктест SMC-схемы (sweep → CHoCH → зона 0,5–0,786 + FVG) с комиссией | То же |
| `pine/smc_volume_gex.pine` | Индикатор TradingView: SMC-сетап с SL/TP/RR, подсветка объёмных свечей, линии GEX | TradingView. **Не компилировался** — вставить в Pine Editor и прислать ошибки, если будут |

```bash
python3 gex_levels.py BTC            # или ETH, --json для бота
python3 volume_anomaly.py BTCUSDT --tf 5m --months 2026-07 2026-08
python3 volume_anomaly.py BTCUSDT --tf 15m --source live --limit 500   # на сервере, где fapi не заблокирован
python3 smc_backtest.py ETHUSDT --tf 5m --months 2025-09 2025-10 2025-11 2025-12 2026-01 2026-02 2026-03 2026-04 2026-05 2026-06 2026-07 2026-08
```

## Как читать объём на 5m/15m свече

Биржа для каждой свечи знает, сколько купили **по рынку** (taker buy) и сколько продали по рынку. Дельта = покупки − продажи. У каждой сделки есть пассивная сторона — лимитные заявки в стакане.

| Свеча | RVOL | Размер свечи | Дельта | Что это |
|---|---|---|---|---|
| ABSORB_BULL | ≥2,5× | обычная (≤1,2× медианы) | сильно − | Продавали по рынку, цена не упала: крупный лимитный покупатель забрал всё |
| ABSORB_BEAR | ≥2,5× | обычная | сильно + | Покупали по рынку, цена не выросла: крупный лимитный продавец |
| CLIMAX_UP/DN | ≥2,5× | широкая (≥2×) | по направлению | Импульс или истощение |
| DIVERGENCE | ≥2,5× | любая | против закрытия | Свеча вверх, а по рынку продавали (и наоборот) |
| SWEEP | любой | прокол экстремума за 48 свечей и возврат | — | Сняли стопы/ликвидность |

«Большой объём, а свеча обычная» — это ABSORB: усилие без результата.

## Результаты проверки на истории

Binance USD-M, данные `data.binance.vision`, запуск 27.09.2026. Комиссия 0,1% за круг [оценка], сверить со своим уровнем.

**Объёмные события, закрытие через N свечей, среднее движение в сторону сигнала (без комиссии), 03–08.2026:**

| | BTC 5m | BTC 15m | ETH 15m |
|---|---|---|---|
| ABSORB_BULL, +12 св. | +0,049% (n=68) | n=2 | n=2 |
| CLIMAX_DN, +12 св. | −0,032% (n=1410) | −0,102% (n=382) | −0,042% (n=371) |
| SWEEP+ABSORB, +12 св. | +0,002% (n=1306) | +0,038% (n=464) | +0,059% (n=505) |
| Среднее \|движение\| за 12 св. | 0,288% | 0,501% | 0,652% |

Вывод: ни один объёмный сигнал сам по себе не перекрывает ~0,1% комиссии. После CLIMAX_DN цена чуть чаще откатывает вверх, но это меньше комиссии. Объём — фильтр и контекст, не самостоятельный вход.

**SMC-схема (стратегия D) — ТАБЛИЦА НИЖЕ НЕВЕРНА: аудит нашёл ошибку исполнения лимиток, после исправления −0,02…−0,22R. См. REPORT.md.**

| BTC | 12 | 58% | +0,41 | +5,0 | +2,5% |
| ETH | 19 | 37% | −0,04 | −0,8 | −0,4% |
| SOL | 26 | 46% | +0,34 | +8,7 | +4,3% |
| XRP | 23 | 48% | +0,39 | +9,0 | +4,5% |
| DOGE | 24 | 25% | −0,38 | −9,1 | −4,5% |
| **Итого** | **104** | | **≈ +0,12** | **+12,8** | |

Первая версия бэктеста показывала +9…+47% за год. Причина — подглядывание в будущее: зона считалась по максимуму той же свечи, FVG брался с той же свечи, лимитка «исполнялась» без касания. После исправления преимущество ≈ +0,12R на сделку при стандартной ошибке ≈ 0,15R — **статистически неотличимо от нуля**. Сделок мало: 1–2 в месяц на монету. RR 7,16 из ролика @mralbash на истории не подтверждается: схема с RR≥3 почти не даёт сделок.
