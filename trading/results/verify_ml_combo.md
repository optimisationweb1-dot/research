## 5. Null-тест: случайное время входа

Выходы — точная логика движка (стоп/тейк = close ± 2·ATR, H = 24, издержки). Число сделок на символ-месяц и доля лонгов/шортов сохранены, 2 000 перестановок.

| OOS base, 20 ближайших баров по стопу% | +0,090 | −0,115 | 0,042 | 0,0005 |
| OOS harsh, кластеры | +0,071 | −0,157 | 0,079 | 0,002 |
| IS base, кластеры | +0,033 | −0,104 | 0,046 | 0,002 |
| IS base, 20 ближайших по стопу% | +0,031 | −0,034 | 0,030 | 0,016 |
| Альтернативный сплит (t2_raw_15m), кластеры | −0,138 | −0,133 | 0,081 | 0,52 |

**Как читать.** p-value маленькое, но null сильно отрицательный: случайный вход в ту же скобку в те же месяцы стоит −0,10…−0,16R. Причины: издержки ~0,07R, правило «стоп раньше тейка в одном баре» и то, что в месяцы, когда модель торгует, лонг в случайный момент убыточен. Поэтому тест показывает одно: модель выбирает момент внутри месяца лучше случайного, то есть покупает сразу после капитуляции, а не посреди падения. Прибыльности он не доказывает. Абсолютный результат после издержек ≈ 0, кроме двух событий (04.2025, 10.2025). На альтернативном сплите преимущество перед случайным входом исчезает (p = 0,52).

## 6. Вердикт

| критерий (исходный сплит) | значение | выполнен |
|---|---|---|
| OOS avg_R > 0 при base | +0,090 | да |
| OOS t ≥ 2 | 1,87 (t_day 0,76) | нет |
| harsh > 0 | +0,071 | да |
| ≥ 6/10 символов в плюсе | 8/10 | да |
| доля конфигов с OOS > 0 ≥ 0,5 | 0,33 | нет |

- По букве правил на исходном сплите — **WEAK**, заявление автора воспроизведено точно.
- Исправленный вердикт — **NO_EDGE**. Почему:
  1. На альтернативном сплите тот же протокол выбирает конфиги с OOS −0,14R, t ≈ −2,3…−2,7, harsh ещё хуже.
  2. Весь плюс OOS дают 2 месяца: без апреля 2025 t = 0,5, без апреля и октября 2025 avg_R ≈ 0.
  3. P(avg_R ≤ 0) по недельному бутстрэпу — 0,16.
  4. IS t = 0,98: в периоде обучения edge не было.
- Автор сам пишет «effectively no tradable edge», и с этим я согласен. Слабое, но реальное наблюдение: после резкого рыночного обвала лонг с широким стопом (2·ATR на 1h) у модели лучше случайного входа в том же месяце. Это кандидат для отдельной заранее зарегистрированной гипотезы «покупка после ликвидационного каскада» с проверкой на новых данных с 2026-09, а не торгуемый результат ml_combo.

## Замечания о движке

Ошибок движка не найдено. Для рыночного входа `simulate` проверяет стоп и тейк уже на баре входа, сначала стоп. Это консервативно и вносит в любую скобочную стратегию постоянный отрицательный сдвиг (у случайного входа валовый R ≈ −0,02 для лонга). Автор это учёл в метках.
